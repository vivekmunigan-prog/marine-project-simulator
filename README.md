# Marine Project Engineering Simulator

Independent engineering portfolio project by Vivek Chander Munigan.

A standalone browser application for marine project schedule scenarios, deliverable tracking, stakeholder response deadlines, issue resolution, lessons learned, change records and instant reporting.

## Run

Open `index.html` in a modern browser. No installation, build step or external dependencies are required.

## Publish with GitHub Pages

In Settings → Pages, choose **Deploy from a branch**, select **main** and **/(root)**, then save.

Expected address after Pages is enabled: https://vivekmunigan-prog.github.io/marine-project-simulator/

## Use and limitations

- Demonstration data is fictional.
- Project records are saved only in the current browser; use the workspace JSON backup export regularly.
- Reply tracking is manual. Reminders open an email draft; the user sends it and records that action.
- The schedule simulator uses a deterministic calendar-day model. Procurement overlap is illustrative and requires authorised engineering review.
- Completed issues and tasks require recorded verification evidence.
- Reports are downloadable HTML snapshots or printable PDF through the browser.
